# AME-2 Scale Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; execution and local main merge are authorized.

**Goal:** Reduce memory and improve parallel IPC throughput without changing task semantics.
**Architecture:** Shared MultiMesh geometry, indexed/fused rays, bounded CPU frontend, lossless SFC storage.
**Tech Stack:** Installed Isaac Lab 3.0/Newton, Warp, Torch float64 QP, NumPy, pybind11.
**Spec:** `docs/superpowers/specs/2026-11-03-ame2-scale-design.md`.

## Global constraints

20,000 rays/10 Hz/40 m; 300 Hz physics/100 Hz control; PCD radius 0.25 m; preserve all QP constraints,
recovery, per-environment observations, source timestamps and preexisting files. No package edits.

## Review focus

Partial resets; cached geometry under different transforms/scales; concurrent planner state;
immutable shuffled rollout contexts; stale ray windows versus sensor update times.
