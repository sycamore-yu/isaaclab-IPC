# 默认使用 PathCover/RISP 生成走廊

用户审阅已有结果后，明确要求将 PathCover 作为默认设计。
剩余 3 组森林测试尚未完成；该缺口继续保留，不作为切换前置条件。

只替换单多面体生成，保留 IPC A*、点云历史、走廊时序、MPC 与物理。
使用 PathCover 的 RISP 内核，将 `Ap≤b` 转为 `[A,-b]`。
通过 `b -= r*norm(A_row)` 保留原配置的安全距离。
删除旧走廊运行实现和构建依赖，不保留运行时切换选项。
历史测试、来源和录制保持原样。

接口、源码版本和测试记录见 [走廊说明](../pathcover.md)。
