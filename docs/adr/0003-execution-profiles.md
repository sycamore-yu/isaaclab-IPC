# 保留理想对照，真实配置默认制动重规划

用户于 2026-11-02 明确批准两种执行配置。
本决策补充 ADR-0001，不改变 A*、SFC 硬约束与固定成本 jerk-MPC。

- `ideal` 保留原避障测试的速度置零、规划位置直接赋值和上一 jerk 序列回退。
- `real` 使用 Newton 刚体与实际速度，QP 失败时默认制动并重新规划。
- `real` 是当前评估入口和 `Config.load` 的默认配置。
- 真实配置的恢复策略属于获准改动，不计为原版严格复刻的新增成功。
- 原版 Docker、理想配置和真实配置必须分开统计。

制动阈值、执行流程和有效结果只在 [执行配置](../execution-profiles.md) 维护。
该策略已默认启用，但中速突现障碍仍为 0/10。
算法改进或架构重构不能改写历史结果。
